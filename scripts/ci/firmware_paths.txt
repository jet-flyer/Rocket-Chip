# RocketChip firmware path list - ONE tracked source of truth.
#
# Readers (keep them in step; do not copy this list into code):
#   - cmake/rc_version.cmake          [elf]  -> kFirmwareTreeId in version.h
#   - scripts/firmware_tree.py        all    -> build-ID gate, bench-note key
#   - scripts/ci/pre_commit_matrix.py all    -> pre-commit build trigger,
#                                               pre-push bench trigger
#   - scripts/ci/check_elf_paths.py   [elf]  -> list-completeness check: every
#                                               repo file a flight build used
#                                               must be in [elf]
#
# Entry forms:
#   dir/       every path under dir/
#   name       that exact path, or every path under name/ (git literal pathspec)
#   prefix*    any path that starts with prefix (NOT allowed in [elf])
# Lines starting with '#' are comments. Paths are repo-relative, '/' only.
#
# Changing this file changes which commits get a bench run. Removing a path
# needs the repo owner's OK (and a council, per the matrix policy).
