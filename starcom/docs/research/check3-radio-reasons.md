# Check 3: radio reasons, still true? (Buzz, 2026-10-06 CT)
Status: REFERENCE ONLY. Nothing decided. All rows are datasheet/doc-only. Nothing board-measured. Datasheet revisions are not yet pinned.

| Project | Stated radio reason (quote) | Chip (source) | Still true today? |
|---|---|---|---|
| OreSat / UniClOGS | GFSK 50 kb/s "was chosen for the capability of the Engineering transceiver radio on the spacecraft" (uniclogs-hardware README @5c0cd713) | OnSemi AX5043, UHF 436.5 MHz TRX + L-band 1.265 GHz RX ([oresat-c3-hardware README](https://github.com/oresat/oresat-c3-hardware); [oresat-c3-rf](https://github.com/oresat/oresat-c3-rf)) | **Changed.** OSU Space Grant poster, spring 2026: AX5043 "discontinued in 2022", "Only supports standard radio protocols (e.g. FSK, ASK, MSK)", "Slow data rates, from 0.1 kbps to 125 kbps". OreSat1 moves to Microchip AT86RF215 (OFDM, QPSK, O-QPSK, 2.4 GHz, up to 2.4 Mb/s). [poster PDF](https://spacegrant.oregonstate.edu/sites/spacegrant.oregonstate.edu/files/2026-06/halsaadon_utep_posterpdf_spring-2026.pdf). The reason was true for the flown radio. The chip is end-of-life. |
| OpenLST | No stated reason for non-CCSDS. Intro: "437MHz at 3kbps". Spec table: 2FSK, "User data rate 7.4 kBaud". | TI CC1110 SoC, 27 MHz xtal, Qorvo RFFM6403 PA (USERS_GUIDE @b996935a) | **Rate mismatch reconciled (inference).** Default mode is `amateur_rf_mode_437_7k_FEC`. Registers DRATE_E=8, DRATE_M=32 at 27 MHz give (256+32)*2^8/2^28*27e6 ≈ 7416 Bd. With the chip's rate-1/2 FEC that is ≈3.7 kb/s, so "3 kbps" user rate after framing fits. Sync word is 16 bits (`RF_SYNC_WORD1/0` = D3 91). CC1110 has the same 16-bit / repeated-16-bit sync limit as CC1101, so a CCSDS ASM cannot be matched in hardware. |
| SX-USP | Sync "Optimized for the first 32 bits being detected by the single-chip transceiver in low-power receive mode"; design goal "Suitable for usage with low-power single-chip transceivers" (README) | **Not named** in README | **Holds only for chips with a true 32-bit sync detector.** First 32 bits 0x5072F64B are not a repeated 16-bit word, so CC1101/CC1110 cannot match them in hardware. SX1276/RFM95 FSK sync is 1 to 8 bytes, so it can match all 64 bits. Which chip they meant is unknown. |
