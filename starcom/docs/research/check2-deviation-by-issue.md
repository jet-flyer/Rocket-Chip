## How to read this file

- "Quote" text is exact book text from pdftotext. I joined line breaks and dropped page headers and footers. Nothing inside quote marks is a paraphrase.
- Page = the page footer that closes the page holding the text (same rule as the map).
- **INFERENCE** marks my reasoning, or reasoning copied from the map. It is not a quote and not a checked fact.
- Verdict words:
  - DEVIATION: the project's stated item conflicts with a "shall"/"must" or an M item, and the project calls it out of spec, or the map shows the clash.
  - ALLOWED: the book lists the choice as an option or allowed value.
  - OPEN: the book text is clear, but the verdict needs a project fact that the project does not state, or the verdict rests only on INFERENCE. I do not guess these.
  - n/a: the row is an issue fact or scope statement, not a design choice.
  - UNVERIFIED: I could not get the issue. (No row needed this. See section 7.)
- Draft words: KEEPS / CHANGES / DROPS / no draft.
- "What changed" compares the verdict under the project's issue with the verdict under the current Blue Book.

## 9. (e) Surprises inside the books

1. **Current Blue Books still cite the superseded SDLS issue.** 232.0-B-4 ref [7], p. 1-6, and 132.0-B-3 ref [10], p. 1-6, both read "Space Data Link Security Protocol. Issue 1. Recommendation for Space Data System Standards (Blue Book), CCSDS 355.0-B-1." 732.1-B-2 ref [15], p. 1-8, did too. 355.0-B-1 has no USLP text at all (§1.1, p. 1-1, names TM, TC and AOS only). So under 732.1-B-2, the SDLS book it pointed to did not cover USLP.
2. **732.1-B-1 made CRC-32 mandatory in its PICS**, not optional: "USLP-148 CRC-32 Encoding Procedure B2.1 M"; "USLP-149 CRC-32 FECF Decoding Procedure B2.2 M" (p. A-10). B-2 replaced USLP-98 with "[Requirement Deleted]" (p. A-8).
3. **732.1-B-1 Table 5-1 has no note 5** ("Insert Zone may only be present when Physical Channel Frame Type is equal to Fixed Length."). B-1 Table 5-1 (p. 5-2) has notes 1–4 only. B-2 added note 5.
4. **131.0 changed its default randomizer in B-5, not B-6.** B-3 and B-4 define only the 255-bit sequence. B-5 already has the 131071-bit "shall" and the "legacy" 255-bit "may". B-6 removed the escape clause and the "Absent" value.
5. **ccsds.org silver list mislinks USLP.** The entry "CCSDS 732.1-B-1-S" has no PDF link. The entry "CCSDS 732.1-B-2-S" links 732x1b1s.pdf, which is B-1.
6. **SDLS TC rule narrowed.** B-1 §5.2 c), p. 5-1: "c) each SA shall be associated to one VC and one VC only." B-2 §5.4 c), p. 5-3, adds "if COPs are used".
7. Not in the books but seen: Yamcs docs label "CCSDS 131.0-B-4" and link 131x0b5.pdf; they label "CCSDS 732.1-B-2" and link 732x1b3e1.pdf.
