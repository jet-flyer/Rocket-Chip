## How to read this file

- "Quote" text is exact book text from pdftotext. I joined line breaks and dropped page headers and footers. Nothing inside quote marks is a paraphrase.
- Page = the page footer that closes the page holding the text (same rule as the map). Pages were found by script (/workspace/tmp/c2/pg.py).
- **INFERENCE** marks my reasoning. It is not a quote and not a checked fact. INFERENCE sits only in the "Note" column and in the "INFERENCE" lines of section 4.
- Verdict words (same as check2-deviation-by-issue.md):
  - DEVIATION: the item conflicts with a "shall"/"must" or an M item, and the project calls it out of spec, or the clash is shown. "(INFERENCE)" after the word means the clash rests on a step I marked.
  - ALLOWED: the book lists the choice as an option or allowed value.
  - OPEN: the book text is clear, but the verdict needs a project fact the project does not state, or the only clashing text is informative.
  - n/a: no clause covers the item, or the row is a scope or issue fact.
  - UNVERIFIED: I could not get the text or fact.
- Draft words: KEEPS / CHANGES / DROPS / no draft.
